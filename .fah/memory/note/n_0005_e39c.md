# Note: n_0005_e39c

Java upstream (dm.ai) has a tool-alias mechanism: @MCPTool(aliases={...}) declares 11 tracker_* aliases on BOTH JiraClient and AzureDevOpsClient (get_ticket, search, post_comment, get_comments, assign_ticket, move_to_status, link_tickets, create_ticket, download_attachment, get_user_by_email, get_my_profile), resolved by McpCliHandler.resolveToolAlias() via env DEFAULT_TRACKER (and DEFAULT_SOURCE_CODE for source_code_*).
