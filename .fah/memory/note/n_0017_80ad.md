# Note: n_0017_80ad

Dart tool surface is canonical-only by design: JS wrappers and ToolBridge resolve canonical tool names (parity with Java exposeMCPToolsUsingGenerated), while aliases are metadata honored via ToolDefinition.applyParamAliases plus the tool-level tracker_* map in ToolBridge/CliDispatcher.
