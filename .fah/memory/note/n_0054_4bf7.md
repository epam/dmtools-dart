# Note: n_0054_4bf7

dmtools-agents PR #352 (feat/fa-provider) final shape (2026-09-08, owner decisions applied): (1) NO legacy shim — fa provider script requires FA_PROVIDER_CONFIG (JSON: baseUrl+model mandatory, optional apiKeyEnvVar) strictly; flat FA_PROVIDER_MODEL/BASE_URL/API_KEY are rejected. (2) setup/dmtools.sh stays the Java DMTools CLI (epam/dm.ai v1.7.x) as the DEFAULT runtime, byte-identical to pre-PR. (3) dmtools-dart is OPT-IN only: setup/dmtools-dart.sh + install.sh OPT_IN_TOOLS list — installs via explicit `install.sh dmtools-dart`, never part of `install.sh all`, side-by-side at ~/.dmtools-dart/bin (both CLIs ship a `dmtools` binary; wrapper exports DMTOOLS_INSTALL_DIR/DMTOOLS_VERSION so the upstream installer honors them). fa install: IstiN/flutter_agent_harness GitHub Releases asset fa-<macos|linux>-<arm64|x64>.tar.gz (bundle/bin/fa + bundle/lib → bin/ + ../lib), fa1.dev fallback. fa headless contract: `fa --session <name> --session-root <dir> -p "<prompt>"`, preconfig pins all model roles, FA_PROVIDER_API_KEY maps into the config's apiKeyEnvVar only inside the fa subprocess.
