# Note: n_0059_0405

Issues-driven dev loop (dmtools-dart PR #18 @ 8edf7d7): machine-kit/templates/ai-teammate-issues.yml — self-contained trigger (on: issues [assigned, labeled]; guard picks runner: assignee==ai-teammate OR label agent:dev → runners/fa-code-zai.json, label agent:review → runners/fa-review-kimi.json; issue body → input/ticket.md; dmtools run <runner> with AI_AGENT_PROVIDER=fa + key secrets ZAI_CODE_KEY/KIMI_REVIEW_KEY from repo secrets named like dmtools.env entries). Self-contained ON PURPOSE (ticket prep must happen in the same checkout — the Jira-era reusable ai-teammate.yml workflow_call can't be used). Chain: issue → agent run → PR Closes #NN → merge-trigger-issues.yml (pr_approved). Runners overridden name=CliAgent (issues flow has no Jira; CliAgent ignores Teammate-only inputJql, reads input folder) — verified via RunCommandProcessor. YAML gotcha: workflow `name:` value with ' : ' must be quoted.
