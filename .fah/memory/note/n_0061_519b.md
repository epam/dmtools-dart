# Note: n_0061_519b

GitHub-aware inputJql (dmtools-dart PR #18 @ 25af9c8, FINAL owner design): variations override params.inputJql in inherited runner configs with GitHub search queries (e.g. "repo:${GITHUB_REPOSITORY} is:issue is:open label:bug") — Teammate mechanism unchanged, agents as-is. lib/src/agents/github_ticket_source.dart: looksLikeGithubQuery routes GitHub vs Jira JQL (tokens is:issue/is:pr/repo:/label:/assignee:/state:/type:issue); expandEnvRefs resolves ${VAR}; /search/issues → issue+comments hydration into raw-tracker shape (key GH-<n>, fields.summary/description/status/labels/comment.comments[].author.displayName); repo qualifier MANDATORY (repo: or GITHUB_REPOSITORY env — else StateError); auth via GithubHttpClient(PropertyReader()) → SOURCE_GITHUB_TOKEN/GITHUB_TOKEN. TeammateJob skips Jira trace comments in github mode. input-first pass-through (input/ticket.md → synthetic ticket) retained as the secondary path. Runners: fa-bug-dev (label:bug), fa-story-dev (-label:bug), fa-review-kimi (label:agent:review) — all Teammate configs with parent name/context intact. Gotcha: Dart test files must escape \$ in ${VAR} literals (heredoc/python writes mangle interpolation); workflow name values with ' : ' need YAML quotes.
