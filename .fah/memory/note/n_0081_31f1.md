# Note: n_0081_31f1

dmtools-dart CI runners (GitHub Actions, this repo's agent jobs) have NO Dart SDK preinstalled. Working setup: download dartsdk-linux-x64-release.zip from storage.googleapis.com/dart-archive/channels/stable/release/latest/sdk/ and unzip to /opt/dart-sdk, then PATH=/opt/dart-sdk/bin:$HOME/.pub-cache/bin:$PATH. `make native` works after pub get (clang+cmake present); crap4dart 0.9.5 via `dart pub global activate crap4dart`. Also: `test/cli/cli_dispatcher_test.dart` teammate no-inputJql test fails in job checkouts because the machine's untracked `input/ticket.md` sits in the repo root — pre-existing/environmental, green on clean CI.
