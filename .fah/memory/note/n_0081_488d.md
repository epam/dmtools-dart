# Note: n_0081_488d

Running `dart test` in a dmtools-dart checkout that has the agent-harness `input/ticket.md` at the repo root makes test/cli/cli_dispatcher_test.dart "executes a teammate job without inputJql as a no-op success" FAIL: TeammateJob._preparedInputTicket() reads `<Directory.current>/input/ticket.md` and treats the harness task context as a prepared input, running the config through a CliAgent instead of returning empty results. The folder is git-ignored, so CI is unaffected. Workaround when running the suite locally in such checkouts: `mv input input.__harness__` before `dart test`, restore after (agents-suite run included).
