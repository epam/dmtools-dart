# Note: n_0089_3f4d

crap4dart is a CI quality gate with a 60-line method_size limit; the pre-commit hook silently skips when ~/.pub-cache/bin is not in PATH (typical for non-interactive shells), so before pushing run the full local sequence: dart format --set-exit-if-changed, dart analyze, dart test --coverage, coverage ≥80%, crap4dart check --all, crap4dart analyze.
