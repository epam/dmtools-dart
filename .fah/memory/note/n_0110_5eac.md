# Note: n_0110_5eac

Root cause of the timer 'no ticketKey' bug is in Dart: `cli_agent.dart` `_runContextJsAction` never passes `ticket` into the JS context (unlike `_executeJsAction`); plan is convention-based hydration — CliAgent reads `input/<contextId>/ticket.json` when ticketData is empty, and the workflow writes that file (build() does not clean the input folder).
