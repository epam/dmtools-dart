# Note: n_0132_7bbc

GitHub tracker surface landed (commit 8e0e36a, 2026-09-11): the unified tracker_* family resolves to the GitHub carrier with DEFAULT_TRACKER=github. New issue-family tools port Java GitHubIssues (dm.ai 9560442): github_get_issue/github_create_issue/github_close_issue/github_reopen_issue (composite 'owner/repo#123' key beats owner/repo/number; bare-number key uses SOURCE_GITHUB_WORKSPACE/REPOSITORY defaults), github_search_issues (repo: scoping unless explicit qualifier), github_move_issue_to_status (done/closed/completed/resolved→close; open/reopened/reopen/todo/backlog/'in progress'→reopen; else→label), github_assign_issue (POST assignees). tracker_* aliases: get_ticket, search, post_comment(github_create_comment), move_to_status, add_label, remove_label, get_comments(github_get_pr_comments), get_my_profile(github_test), create_ticket, assign_ticket. JS bridge stays canonical-only (Java parity); aliases resolve CLI-side. Catalog 61→65 tools; JS-bridge execution via GitHubSyncTools handlers. For the issue-trigger project: adapter scripts can now use params.ticket-driven tracker_* or canonical github_* names.
