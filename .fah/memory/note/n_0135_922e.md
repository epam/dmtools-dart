# Note: n_0135_922e

Config chain is Java-exact since 952790e (P6-CFG-01..05, W2, 2026-09-11): overrides → config.properties (<root>/src/main/resources from disk wins even if empty, else setConfigFile resource — Dart classpath substitution = filesystem path) → dmtools.env (project root FIRST then CWD, skipped when equal; empty-parse file skipped for the next candidate; unreadable file warns+continues) → OS env. Empty values fall through file tiers (non-null AND non-empty to accept). Root marker = settings.gradle(.kts) with CWD fallback — NOT pubspec.yaml. BREAKING: the dmtools-local.env tier is REMOVED (Java has none, P6-CFG-03) — local credentials must live in dmtools.env. Docs updated in README/GOAL.md/test/integration README. E2E note: produced by the first full subagent pipeline (explore→worker→review→fixer); task_send/child-messaging and task_observe are NOT available on this host — completed agents can't be resumed, spawn new ones instead.
