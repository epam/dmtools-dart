# Note: n_0147_0f7a

In dmtools-dart, fa-session.sh writes .dmtools/fa-sessions/** into .git/info/exclude of each checkout, so agent commit-flows using `git add .` with negation-pathspecs fail with 'paths are ignored' — files must be staged explicitly (e.g. `git add .github/workflows/ai-teammate-issues.yml`).
