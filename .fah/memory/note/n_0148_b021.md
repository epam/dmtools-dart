# Note: n_0148_b021

The GitHub Actions checkout App token (github-actions[bot]) lacks `workflows` permission, so any push touching .github/workflows/* is rejected — machine pushes to workflow files must go through a PAT (SOURCE_GITHUB_TOKEN).
