# Note: n_0198_4d2c

Java reference behavior: JavaScriptExecutor.execute() flattens jobParams, ticket, response and every .with(key, value) into one global params JSONObject; scripts read params.inputFolderPath etc., so the Dart port must merge extraGlobals into params while keeping top-level globals as a superset (PR #90).
