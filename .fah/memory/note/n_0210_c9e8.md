# Note: n_0210_c9e8

dmtools-dart quality gate gotcha: coverage/ and the gates that read it (test_coverage, crap4dart analyze) silently use STALE lcov data when the dart test --coverage run is skipped in the same session — a piecemeal "green" local run can still fail CI (real case: gh-125 rework #127, _Converter._openFence CRAP 8.63 failed in CI because the local crap4dart run read coverage/ from an earlier session before the code changed). Always run the full local sequence as ONE pass with a fresh coverage dir: rm -rf coverage && dart format --set-exit-if-changed . && dart analyze && dart test --coverage=coverage && dart pub global run coverage:format_coverage --lcov --in=coverage --out=coverage/lcov.info --report-on lib && crap4dart check --all && crap4dart analyze.
