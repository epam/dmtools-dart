# Note: n_0214_f0e1

crap4dart/coverage gotchas (dmtools-dart): (1) Local coverage formatting MUST mirror CI exactly — `dart pub global run coverage:format_coverage --lcov --in coverage --out coverage/lcov.info --report-on lib` WITHOUT `--check-ignore`; --check-ignore silently drops whole files (e.g. teammate_job.dart), producing phantom CRAP 42.0/30.0 "0% coverage" failures that look like regressions but reproduce on a clean tree. (2) Two different complexity bars: the `complexity` gate allows CC≤10, but the CRAP-score gate (threshold 8.0) means a fully-covered method needs CC≤8 (CRAP=CC at 100% cov); methods AT 8.00 pass, 10.00 fails. Design new methods to CC≤8 — split routing ladders/flag parsing into private helpers. (3) 3 known local-only test failures (allowed_base macOS temp-dir + 2 github no-defaults caused by the local gitignored dmtools.env) — CI green, reproduce via `mv dmtools.env /tmp/` before comparing.
