# Note: n_0215_09a3

GitHub Actions gotcha (live-verified 2026-09-19 on flutter_agent_harness): mapping `github.token` through the `secrets:` block of a reusable-workflow call delivers an EMPTY value to the callee, even when the callee declares the secret — push happened with the ambient PAT instead of the silent token. Fix: pass it as a workflow INPUT (`silent-token: ${{ github.token }}`); inputs carry it fine and GitHub auto-masks token values in logs regardless. Pattern shipped in dmtools-agents factory-sm.yml (input `silent-token`, env `inputs.silent-token || secrets.SILENT_GH_TOKEN`).
