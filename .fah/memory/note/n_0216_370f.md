# Note: n_0216_370f

dmtools-dart bridge parity fixes (v0.1.15/v0.1.16, surfaced by the live SM loop on flutter_agent_harness #687): (1) sync tools returning plain strings (github_trigger_workflow, github_get_workflow_run_logs) must jsonEncode the result — quickjs_bridge.c parses host results with JS_ParseJSON and throws "host callback returned invalid JSON" on raw text, making successful dispatches look like failures; cli_execute_command is the precedent. (2) set_env_variable was a Phase-1 no-op stub; now merges a real PropertyReader.setOverride(name, value) — cli_execute_command applies getOverrides() last when building the child env, so JS-side env swaps (the SM's GH_TOKEN silent swap around `gh pr update-branch`) reach child processes, matching Java SetEnvVariableProxy semantics.
