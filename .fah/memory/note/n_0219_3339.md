# Note: n_0219_3339

Owner rule (2026-09-21, machine loop): the `ai-teammate` account is the ONLY account whose PRs get the rework leg. Every other account is a guest of the repo — guests get review + validation only, NEVER an auto-rework arm (they fix their own findings; the SM re-validates on push). Implemented: SM auto-rework rule `prMachineAuthor: true`, PR-anchored verdict re-arm `prAuthor === machineAuthor`, and (dmtools-agents #482, factory d6c45fb) fail_validation re-arm machine-author-only with guest report "fix and push". `machineAuthor` unconfigured ⇒ fail-closed (no rework arms at all) per js/common/machineAuthor.js. Note: manual `agent:rework` label ON a PR still allows any author to explicitly request rework — kept as deliberate human action.
