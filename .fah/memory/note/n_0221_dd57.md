# Note: n_0221_dd57

Factory pin sed on macOS: BSD sed -E does NOT support \s — the (factory_ref:\s*)sha replacement silently never matched, leaving uses@ on the new sha while factory_ref stayed on the old one (2026-09-22: skew acc3ded→54e86fd on BOTH fa and dmtools-dart main; caught by factory_stub_ref_test "factory_ref must repeat the uses-ref literally", red on main + every refreshed branch). ALWAYS pin with python re.sub (r'(factory_ref:\s*)[0-9a-f]{40}'), never sed with \s. Fix PRs: fa #851, dart #225.
