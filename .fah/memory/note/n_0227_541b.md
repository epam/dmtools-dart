# Note: n_0227_541b

node/js compat layer in Java dm.ai (PR epam/dm.ai#587, commit 3dadf16d, branch feat/runasync-parallel-js): JsNodeCompat.install(context[, config]) mirrors quickjs_runtime#4 (Dart is the reference) — Tier 1 real (global/console/process/posix [REDACTED_SECRET] pure-JS/atob[REDACTED_SECRET]/require builtins + consumer registry installModule + RequireProxy fallback) + Tier 2 typeof-safe call-time stubs (Buffer/fetch/AbortController/timers/nextTick) with byte-identical Dart alternative texts. Knob: params.jobParams.nodeCompat === true, default-off; installed on main path AND runAsync worker engines. Interop constraint under allowAllAccess(false): hook proxies exchange primitives only (String/int/double) — that's why utf-8/base64 are pure JS and installModule returns string-valued exports (fs-mapping seam for a later bridge proxy). JsNodeCompatTest 18/18 scenario-mirrors the quickjs_runtime suite; full :dmtools-core:test green.
