# Note: n_0229_989b

gh-257 resolved (2026-09-26): the AgentPackResolver._toAbsolutePackPath CRAP 10.04 was NOT a sharded-lcov merge artifact (ticket theory wrong) — CI's `coverage:format_coverage --lcov` emits NO BRDA records (no --branches flag), so crap4dart scores CRAP from LINE coverage; the method had 13/14 lines hit (the `while (ref.startsWith('./'))` loop body and _rewriteList's nested map/list branches were never executed by ANY test, local included). Diagnosis method: read DA records for the method's line range in the lcov and solve 100*(1-cov)^3+CC. Fix: added path-rewrite tests (./-prefix, nested list/map shapes, empty/http://absolute/../-escape pins) + extracted _isNonPathRef (CC 10→6); threshold restored to 8.0. Local CI-exact sharded verification recipe: run `dart test --coverage --total-shards 4 --shard-index N` per shard, format each to /tmp, merge with `lcov -a` exactly as quality.yml does (~4-5 min/shard at --concurrency=2), then analyze against the merged lcov. Gotcha: a full unsharded `dart test` on the CI machine got SIGTERM'd at ~35 min in test/js — prefer the 4-shard form (it is the CI semantics anyway and each shard saves its lcov).
