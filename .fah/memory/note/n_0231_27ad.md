# Note: n_0231_27ad

fa machine packs read under $HOME/.dmtools/packs — the DMTOOLS_FILE_READ_ALLOWED_PATHS env var must be set for pack-internal file_read/require to pass the file sandbox. The fa factory workflow (IstiN/dmtools-agentic-workflows factory-teammate.yml) does NOT set it (checked 2026-10-06); Java's own workflows (dm.ai sm.yml) set `../.dmtools/**`. Since gh-367 the Dart port honors the var with Java-exact semantics (comma-separated globs, literal prefix resolved against the working dir, Java PathMatcher glob rules; read-flavored file_* ops only — writes stay strict). For the fa machine workdir /home/runner/work/<repo>/<repo> a value reaching $HOME/.dmtools is `../../../.dmtools/**` or an absolute prefix; wiring options: factory workflow env, pack runner configs (envVariables), or a factory vars passthrough. If pack reads ever fail again with "Path traversal attempt blocked", check this env first.
