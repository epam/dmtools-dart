# Note: n_0231_8628

quickjs_runtime is PUBLISHED on pub.dev (2026-09-24): ^0.3.2 is the good release (0.3.0 missed the fetch/timers stack — stacked PRs merged out-of-band never hit main before tarball build; 0.3.1 shipped a broken native-lib loader path join for hosted checkouts: package_config rootUri has NO trailing slash for hosted vs trailing for git, join made '<root>native/...' — dlopen failed for every pub.dev consumer while git-pin testing stayed green). Publish flow: dart pub publish needs OAuth browser auth once (credentials persist), publish MUST run with explicit cd (wrong cwd = 'private package' error), pub's version-listing cache (~/.pub-cache/hosted/pub.dev/.cache/<pkg>-versions.json) lags up to ~5 min after upload — delete it + retry pub upgrade. Hosted checkouts have NO .so: run tool/build_quickjs.sh inside the pub-cache dir once (Makefile/CI chain covers it). dmtools-dart PR #226 now pins quickjs_runtime: ^0.3.2 hosted (verified: workers+fetch suites green, agents 1096/1096). Lesson: ALWAYS verify the published tarball by consuming it from pub.dev, never by git-checkout tests alone.
