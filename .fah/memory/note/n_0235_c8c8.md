# Note: n_0235_c8c8

Landmine (Java-parity, inherited from JobJavaScriptBridge.java:1014): job_runner.dart `_loadJavaScriptCode` isInline heuristic treats any input containing the substring 'action' as inline JS. Absolute paths under GitHub Actions runners (/home/ubuntu/actions-runner/...) contain 'action' → the PATH STRING gets eval'd → bogus SyntaxError (e.g. 'invalid regular expression flags'). Verified against fresh epam/dm.ai clone — Java has the identical heuristic, so it is NOT a port deviation and no quickjs_runtime PR is needed. Workaround: pass relative paths from tests/configs (this is why PR #226's cross_runtime_conformance_test failed only on the CI VM).
