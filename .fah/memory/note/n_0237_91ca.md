# Note: n_0237_91ca

DECISION (2026-09-24, owner): the reusable workflow hub idea (IstiN/dmtools-agentic-workflows as a versioned, SCM-agnostic home for factory workflows) is APPROVED IN PRINCIPLE but DEFERRED. Keep factory workflows in dmtools-agents with literal SHA pins for now. Trigger for the migration: when dmtools learns to load agents from versioned ARTIFACTS (instead of the git submodule) — at that point the pin==submodule coupling dissolves naturally and hub versioning becomes clean. Design notes agreed during discussion: immutable semver tags, NO mutable latest for machine legs (supply chain — factories run SOURCE_GITHUB_TOKEN machine accounts); version selection via env vars is NOT viable as-is (GitHub jobs.<job_id>.uses has no env context, vars-in-uses unverified, GitLab include:ref forbids variables) — literal pins moved by automation (Dependabot/bot); hub tag must manifest the tested agents SHA; factory_ref stays a required input on machine legs. Open questions (SHA vs protected major tags, vars spike) resolved by the deferral.
