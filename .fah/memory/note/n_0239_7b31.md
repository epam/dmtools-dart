# Note: n_0239_7b31

quickjs_runtime pub package does NOT ship the compiled .so (gitignored, excluded by dart publish). After `pub upgrade`/`pub get` pulls a new hosted quickjs_runtime version, tests hang waiting on dead workers whose dlopen failed — must build the .so inside the pub-cache copy: `bash $PKG/tool/build_quickjs.sh` (PKG = the pub-cache dir of quickjs_runtime). CI always does this in its 'Build QuickJS' step; locally it's easy to miss. Gotcha from colleague session (2026-09-25, PR #246 consumer work for dmtools-dart #242).
