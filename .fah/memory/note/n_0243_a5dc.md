# Note: n_0243_a5dc

fa CI LESSON (2026-09-25, gh-951 misdiagnosis): 'green-run debug output' in CI logs can masquerade as failure evidence — strings like 'Bad state: no scripted instance' / 'PanicException' were EXPECTED stderr of passing failure-handling tests. Before declaring a test failed, verify the EXACT failing test name (❌ / 'Failed to load' lines), not string-presence in logs; and verify the specific shard/job of the FIRST failing run, not later runs (later reds were self-inflicted chain: #950 throw-Skip load failure → #952 broken syntax → #953 setUpAll artifact). The machine (vab) caught the misdiagnosis via forensics and fixed it in PR #960 (re-enable Linux leg). Trust but verify machine PRs — and accept when they refute my own analysis.
