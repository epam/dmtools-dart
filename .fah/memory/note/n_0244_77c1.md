# Note: n_0244_77c1

Machine delivery pipeline (dmtools-agents factory) as one map: (1) TRIGGER — issue assigned to ai-teammate = sole auto-trigger → dev leg (label agent:dev, branch ai/gh-N, CI silent on push); (2) DEV LANE — validate-fresh (checks none/pending, no latches → arm ai_validating + dispatch CI) → green latches ai_validated → review leg (ai_pr_reviewed) → red or REQUEST_CHANGES → agent:rework loop; (3) MERGE WINDOW — pr_approved (STICKY, survives rework) → validate-armed (mutex ai_validating among pr_approved = one validation at a time, oldest first) → merge-validated (rollup green + mergeState CLEAN → squash). Status observation: check rollup green/red/pending/none from head check-runs (CANCELLED ignored = no verdict); mergeState CLEAN/BEHIND/DIRTY/BLOCKED with deterministic base-sha override; BEHIND armed → unarm-stale → silent-update (workflow token, no CI) → re-arm. Three actors beyond SM tick (cron */10 + event dials): sm-kicker.yml (dispatches CI on codeless heads lacking required contexts — by design, no mutex), machine-merge.yml MMB (event-driven fast path merging approved green CLEAN within seconds), ai-teammate.yml (agent legs). Diagram (archify, owner-approved style): site/machine-pipeline.html + site/src/machine-pipeline.workflow.json in dmtools-agents (PR #528). Dead zones fixed 2026-09-26 (#527): revalidate-armed mutex self-block removed; revalidate-armed-green covers armed+green+BLOCKED (lost CI dispatch); skipIfGreenCi stops re-dispatch loops.
