# Note: n_0246_ca8e

RCA 2026-09-28 (ноги висли часами, dmd PR #266 + fa gh-1032): двойная установка git-push-guard shim'а (factory-teammate.yml шаг ставит symlink-копию №1, scripts/run-agent.sh — копию №2, на РАЗНЫЕ файлы) → resolver «настоящего git» пропускал только себя → копии резолвили друг друга → бесконечный exec-пинг-понг на любом git-вызове (в т.ч. внутри `dart test`). Симптом: bash-чайлд живёт часами, wchan anon_pipe_read, fd255 на guard-скрипте, load ~1 при PSI 0; fa крашится при аборте «StreamSink is bound to a stream». Фикс dmtools-agents#558: shim пропускает ВСЕ */git-push-guard.sh при резолве + run-agent.sh не ставит второй shim. Урок: любой PATH-shim обязан пропускать все свои копии, не только self.
