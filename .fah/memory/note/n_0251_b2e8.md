# Note: n_0251_b2e8

In the Fa harness, multiple edit() calls to the SAME file in one parallel batch race: each call snapshots independently and last-writer-wins per region — some edits silently revert (observed repeatedly in dmtools-dart sessions: imports/pins lost, garbage tails resurrected). Rule: never parallel-edit one file; apply sequentially and re-grep every hunk after. Also: this project machine has multiple concurrent Fa sessions in the same repo — expect remote branch moves (merge-bot) and dirty-tree surprises; use git rebase --autostash and verify with git log/diff before pushing.
