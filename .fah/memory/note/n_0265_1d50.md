# Note: n_0265_1d50

Factory state publishing convention (2026-10-01): all three factories (IstiN/flutter_agent_harness, epam/dmtools-dart, IstiN/dmtools-agents) publish SM-tick state snapshots to their repo's `factory-data` branch, assets fa-state.json / dart-state.json / agents-state.json, opt-in via machine-sm.yml `state-publish` input of the pinned factory-sm.yml. Board: dmtools-agents site/factory (schema 2 with lifecycle timestamps; schema 1 back-compat, fresh→pr_created). Dart's tag was `factory-state` until epam/dmtools-dart#322 normalized it. dmtools-agents state only goes live when the tick's smAgent comes from a released agents version (factory resolves agents from releases, not main).
