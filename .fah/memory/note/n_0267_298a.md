# Note: n_0267_298a

Rebase conflict cleanup pitfall (2026-10-01, fa #1177): when a conflict has two adjacent `uses: repo/workflow@SHA` lines (one per side), deleting only <<<<<<< / ======= / >>>>>>> markers leaves DUPLICATE uses keys → YAML "Duplicate mapping key" parse error that silently cascades into totally unrelated guard tests (setup_flutter_selfhosted_test, release_hygiene_test failing with confusing messages). Fix = delete the duplicate uses lines themselves, then run the yaml-parsing test files locally before pushing. Also: git rebase --continue hangs without GIT_EDITOR=true in background jobs.
