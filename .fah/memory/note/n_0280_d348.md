# Note: n_0280_d348

Factory ops: both flutter_agent_harness AND dmtools-agents repos have their own repo-variable knobs (AGENTS_VERSION, DMTOOLS_VERSION, DMTOOLS_PACK_REGISTRY) consumed by their machine-sm ticks. Incident-response pins MUST be unpinned after the fix release ships — 2026-10-10: dmtools-agents ran a 4-day-old pack (agents-rel-20261005-183226, pinned 2026-10-06) so none of the day's agents-side rule fixes were live on its own tick (symptom: #826 CLEAN+zero-labels never armed until unpin). When a repo's tick behaves stale, check `gh variable list -R <repo>` FIRST.
