# Note: n_0283_c2ae

dmtools-dart CI runs on GitHub-hosted `ubuntu-latest` as of 2026-10-12 (owner switched off the dead epam `bitrise-runner-dmtools-ci` pool). A local macOS fallback runner was tried and removed: quality.yml is Linux-only (apt-get/timeout), so macOS runners turn the queue red — never substitute. Root cause of the 22h fa#1457 saga: `github_get_commit_check_runs` fetched a single 30-run page while heads carry 300+ check-runs — fixed by epam/dmtools-dart PR #387 (pagination). Also: crap4dart LOC ratchets are per-file (800) and per-method (60) — big new tests must go in their own files.
