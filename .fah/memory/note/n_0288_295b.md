# Note: n_0288_295b

PyYAML silently dedupes duplicate mapping keys (last wins), but the GitHub workflow parser REJECTS them (0-job startup failure, all legs of the factory die). My awf 75c72a6 added a second `inputs:` block under `workflow_call:` and a yaml.safe_load check passed — factory down for 3 repos until awf#33 (ce4e1518). Rule: after ANY workflow edit run the strict duplicate-key loader (SafeLoader subclass raising on dup keys) over .github/workflows/*.yml, not plain yaml.safe_load.
