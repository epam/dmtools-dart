# Note: n_0289_b048

TWO GitHub workflow-parser traps invisible to local yaml checks (both broke the awf factory for ALL consumer repos on 2026-10-13): (1) PyYAML silently dedupes duplicate mapping keys, GitHub REJECTS them (0-job startup failure); (2) workflow_call INPUTS require `type:` — missing type passes every push/tick and only fails at CALL time with HTTP 422 'Required property is missing: type' on workflow_dispatch (my slot NAME inputs, awf a4cd62f). Secrets don't need type; inputs do. Because ticks/merge-bot ran on OTHER factory workflows (factory-sm/factory-merge), the teammate-leg outage masked for hours. Post-edit validation rule: strict duplicate-key loader + assert every workflow_call input has `type` + one real `gh workflow run` dispatch probe of any edited reusable workflow.
