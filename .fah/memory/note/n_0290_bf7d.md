# Note: n_0290_bf7d

Factory de-bloat policy (owner, 2026-10-13 evening): ALL domain logic of awf factory workflows moves to dmtools-agents as JS modules (CommonJS, TDD testRunner tests, mockable I/O) invoked via `dmtools run ...` — awf workflows become thin GitHub plumbing only (checkout, env, dispatch). Migration order: sh stays + awf A/B harness stays UNTIL EVERY block is ported to JS («пока не переведешь все»), THEN one rewire deletes sh+sh-tests together; dmtools-agents is the single test home afterward. No per-block sh deletion during migration. Pilot: dmtools-agents PR #892 (js/factory/token_usage.js, red->green TDD, 45/45 + jq parity 300/300). Next ports: discovery publish, board/factory-state export, verdict/stat glue — never GITHUB_ENV/Actions plumbing (that stays inline forever).
